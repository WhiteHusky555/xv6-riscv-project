# Пользовательское пространство (User Space)

Директория содержит исходный код стандартных утилит командной строки, системных библиотек и разработанного нами пула стресс-тестов для верификации стабильности изменённого ядра.

## Внедренные программы и библиотеки

* **`uthread.c`**: Пользовательский интерфейс (wrapper) над системными вызовами ядра. Предоставляет программисту функции создания и ожидания легковесных потоков:
    * `pthread_create(void (*fcn)(void *), void *arg)` — динамически аллоцирует изолированный пользовательский стек размером 4 КБ (`PGSIZE`) и вызывает `clone()`.
    * `pthread_join()` — вызывает системный вызов `join()`, приостанавливает поток до завершения параллельной задачи и безопасно освобождает (`free()`) память стека.
* **`pthread_test.c`**: Нагрузочный тест многопоточности. Запускает 4 параллельных потока, выполняющих по 10 000 математических итераций над общим счетчиком через атомарные инструкции GCC `__sync_fetch_and_add`. Чистота вывода в консоль гарантируется кастомным пользовательским спинлоком.
* **`kht_test.c`**: Верификатор конкурентной хеш-таблицы ядра. Проверяет корректность разрешения коллизий при многопоточной вставке и работу логики Copy-on-Write при обновлении ключей.
* **`kill_slp_test.c`**: Тест устойчивости планировщика. Генерирует до 100 дочерних процессов, блокирующихся на системном вызове чтения, и проверяет корректность прерывания сна при отправке сигнала `kill()` с родительского ядра.
* **`polltest`**: Программа тестирования консоли, осуществляющая плотный ввод-вывод в условиях полного отключения аппаратных прерываний UART.

## Изменения в стандартных тестах

* **`usertests.c`**: Модифицирован алгоритм функции `countfree()`. Вместо ресурсоемкого вычерпывания всей памяти системы методом "грубой силы" через циклы `sbrk(PGSIZE)`, функция адаптирована под прямой вызов написанной нами системной функции `getfreemem()`, что сократило время инициализации тестов с нескольких минут до долей миллисекунды.
